# Print and social items (Brand Guidelines p.10)

| File | Size | Use |
|---|---|---|
| `visiting-card-front.svg` | 90 × 50 mm | Card front: primary lockup and tagline |
| `visiting-card-back.svg` | 90 × 50 mm | Card back: name, role, phone, email, address |
| `staff-id-care.svg` | 54 × 85.6 mm (CR80, vertical) | GS Care staff ID (teal G) |
| `staff-id-industrial.svg` | 54 × 85.6 mm (CR80, vertical) | GS Industrial staff ID (navy G) |
| `social-recruitment-mr.svg` | 1080 × 1080 px | WhatsApp / Instagram recruitment post, Marathi first |

How to use
1. Open the file in a text editor and replace every `[PLACEHOLDER]` (name, phone, email, address, staff details).
2. For the social post: open the SVG in Chrome, then use a free SVG-to-PNG converter or Figma/Canva to export a
   1080 × 1080 PNG for WhatsApp and Instagram.
3. For printing: send the SVG to the printer and ask them to **outline the fonts** (Archivo, Manrope, Mukta),
   add 3 mm bleed, and give you a **printed proof and Pantone match** before the bulk run (Brand Guidelines p.06).

These files are regenerated by `node scripts/print-items.js`; edit that script if you want to change the layout
for everyone, or edit a copy of the SVG for one person.
